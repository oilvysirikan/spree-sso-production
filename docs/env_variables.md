# Environment Variables

## LINE Login
| Variable | Description |
|----------|-------------|
| `LINE_CHANNEL_ID` | LINE Login Channel ID |
| `LINE_CHANNEL_SECRET` | LINE Login Channel Secret |
| `LINE_LIFF_ID` | LINE LIFF App ID (for member portal) |

## LINE Messaging API
| Variable | Description |
|----------|-------------|
| `LINE_CHANNEL_ACCESS_TOKEN` | Channel Access Token (long-lived) |

## LINE Pay
| Variable | Description |
|----------|-------------|
| `LINE_PAY_CHANNEL_ID` | LINE Pay Channel ID |
| `LINE_PAY_CHANNEL_SECRET` | LINE Pay Channel Secret |
| `LINE_PAY_ENV` | `sandbox` or `production` |

## PromptPay (Omise/OpnPayments)
| Variable | Description |
|----------|-------------|
| `OMISE_SECRET_KEY` | Secret key (skey_...) |
| `OMISE_PUBLIC_KEY` | Public key (pkey_...) |
| `OMISE_RETURN_URI` | Redirect URL after payment |

## Shopify
| Variable | Description |
|----------|-------------|
| `SHOPIFY_SHOP_DOMAIN` | e.g. `mystore.myshopify.com` |
| `SHOPIFY_ACCESS_TOKEN` | Admin API access token |
| `SHOPIFY_WEBHOOK_SECRET` | Webhook signing secret |

## App
| Variable | Description |
|----------|-------------|
| `APP_URL` | e.g. `https://sv9-whatsstore.silvercloud-6d5.workers.dev` |
